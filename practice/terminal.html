Moving around the terminal: cd and ls

The terminal is a built-in app that allows you to navigate and
control everything about your computer through commands. To get
around, you type cd where you want to go.
"Where you want to go" will be replaced with, you guessed it, where
you want to go. One problem, though: you don't know where you even
can go. That's where ls comes in. Just by typing
ls, the terminal will show you the files and
directories of where you currently are. Try using ls,
and you'll see something like this:

From here, I can use cd followed by anything listed
and the terminal will take me there.
Practice using the cd and ls command by
moving all around your computer. If you ever get lost, type
pwd, and the terminal will output your current
location. In addition, you can use cd .. to go back
one directory or cd (nothing after) to go back to
home, where you started!

A great place for you to practice cd, ls, and more:
Terminus, a web game by MIT students

Fundamentals of Vim

Key commands

Vim is a readily available text editor that allows you to do
many amazing things. For now, we will just use it to create a
simple HTML document. Type cd in the terminal to
return back to home. We'll create the file here, and you can
move it around later to your liking by using mv.
Input vim practice.html. It will bring you into a
new interface with only a line of tildes on the left. Before
you do anything else, press i to enter insert mode and
copy and paste these lines into the file: 


<!DOCTYPE html>
<html>
  <head>

  </head>
  <body>

  </body>
</html>

These are critical aspects of your HTML file. Without them, your
file would cease to function at all.

How to navigate Vim

To move around your file, use:

  • h for left
  • j for down
  • k for up
  • l for right
Or just the arrow keys. Either works; just choose whichever one
tickles your fancy.

To exit insert mode, press the escape
key (esc). You are now in normal mode.
To save, ensure you are in normal mode. Once you are,
type :w and press enter.
NOTE: This will overwrite your past save, so
be careful!
To quit vim and return to the terminal, input :q.
If you have not saved, you may recieve this message:
E37: No write since last change (add ! to override)
